Project Title: NIELIT Automation Mailer.

The Problem: Distributing hundreds of certificates manually was a slow and repetitive task for the staff.

The Solution: I built this Electron app to read a student CSV, match it with PDF files in a folder, and send them automatically using Gmail SMTP.

Key Features:

CSV Parsing: Automatically reads student data.

Batch Processing: Sends multiple emails with one click.

Activity Logs: Generates a CSV report of successful and failed emails.

Tech Stack: Electron.js, React, Node.js, Nodemailer.
